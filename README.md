# IT 145 — Java Application Development Foundations

This portfolio combines two verified IT 145 learning threads: defensive input handling for a paint estimator and object-oriented modeling for a pet-management domain.

## What this demonstrates

- Reusable calculation methods with validation and clear exceptions
- Rounding business results to whole paint cans
- Encapsulation, inheritance, and constructor invariants
- A complete, runnable `Pet`/`Dog` model rather than a partial subclass
- Small, readable Java classes that can be tested independently

## Run

```powershell
javac src\*.java -d out
java -cp out Demo
```
